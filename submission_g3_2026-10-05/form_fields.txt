DATA AVAILABILITY STATEMENT
All benchmark datasets are public: EasyGeSe (https://doi.org/10.5281/zenodo.15348871), the CIMMYT wheat panel distributed with the BGLR R package, and the SoyNAM population distributed with the SoyNAM R package. Source code, frozen benchmark results, cross-validation definitions, selected configurations, and a recorded runtime manifest are available at https://github.com/GBeurier/gs-loss. Supplementary File 1 documents the architecture adaptations, paired contrasts, missingness, calibration, method ranks, and nested-tuning sensitivity. Analysis and simulation code is provided in Supplementary File 2; machine-readable figure and analysis tables and text alternatives are provided in Supplementary File 3.
